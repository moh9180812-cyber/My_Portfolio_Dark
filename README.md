# Personal Portfolio

My personal frontend portfolio: a responsive one-page site that introduces me, my skills and my projects.

**Live demo:** https://moh9180812-cyber.github.io/My_Portfolio_Project/

## Features
- Sections: hero, about, skills, projects, contact
- Project filtering and section navigation
- Contact form and newsletter subscribe form with success and error messages
- Styles split into one CSS file per section

## Built with
HTML, CSS, JavaScript

## Run locally
```bash
git clone https://github.com/moh9180812-cyber/My_Portfolio_Project.git
cd My_Portfolio_Project
```
Open `index.html` in your browser. No build step or install needed.
